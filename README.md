PaisaLens AI – Student Finance Assistant

PaisaLens AI is a student-focused personal finance assistant designed to help students track expenses, manage budgets, understand spending habits, and monitor savings goals.

Features

- Add and delete daily expenses.
- Categorise expenses into Food, Travel, Education, Shopping and Other.
- Visualise spending through charts.
- Set and monitor monthly budgets.
- Create and track savings goals.
- Expense analysis with spending summaries.
- Smart budgeting chatbot using JavaScript-based rules.
- Save expense data in the browser using LocalStorage.
- Responsive mobile-friendly interface.

Technologies Used

- HTML5
- CSS3
- JavaScript
- Chart.js
- Browser LocalStorage

AI Model and API Information

The current submitted version uses a rule-based JavaScript assistant for budgeting observations and chatbot responses.

No live generative AI model or Gemini API is connected in this version. Live AI integration is planned for a future update.

How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in a browser.
4. Start adding expenses and explore the dashboard.

Data and Privacy

Expense entries are stored locally in the visitor's browser using LocalStorage. Do not enter passwords, bank details or other sensitive information.
